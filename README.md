# skyeverse.space — portfolio

Personal portfolio for Aakash Aggarwal. Next.js (App Router), fully static, no backend.
One long scrolling page; all content lives in `data/*.json`, not in components.

```
npm run dev      # http://localhost:3000
npm run build
npm run lint
npm run build:single [dest.html]   # whole site folded into one shareable .html
```

Architecture, design tokens and the rules for editing content are in `CLAUDE.md`.
